## Fresh start each night (handoff)
At about {{HANDOFF_TIME}} the box asks you to write a handoff, then restarts you with an empty context. When asked:
1. Overwrite `~/projects/<your area>/HANDOFF.md` (short, max ~40 lines): work in progress with repo, branch and the very next step; anything you're waiting on the owner for; open PRs. No chat history, no secrets.
2. Reply in the terminal only (not in the chat) with "handoff done".
**After a restart, before answering your first message,** read `~/projects/<your area>/HANDOFF.md` if it exists, and continue from it. Don't re-read whole repos to "catch up"; open only what the next step needs.
