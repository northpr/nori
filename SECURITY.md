# Security

Nori sets up a server that can run code and holds bot tokens, so security reports matter.

**Please don't open a public issue for a security problem.** Report it privately instead:
GitHub → this repo → **Security** → **Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do. You'll get an answer within a few days.

Never put real tokens, keys or passwords in a report; describe them instead.
