# `./nori up` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `./nori up`, which turns either a new Hetzner server (created through the API) or an existing server IP into a working Nori box (bot answering) from the laptop, asking for every key once at the start.

**Architecture:** A small stdlib-Python CLI (`nori` at the repo root) with four focused modules in `scripts/nori/`:
- `config`: the resolved `nori.conf`;
- `keys`: checklist, hidden prompts, checks;
- `hetzner`: API client;
- `remote`: ssh, `~/.ssh/config`.

A fifth module, `stages`, holds ordered, skip-if-done stages and a non-secret state file. On the server side, `set-token` and the systemd units learn one new secret, the Claude token file.

**Tech Stack:** Python 3 stdlib (`urllib`, `json`, `getpass`, `subprocess`, `unittest`), bash, system OpenSSH, systemd user units.

**Spec:** `docs/superpowers/specs/2026-10-09-nori-up-design.md`

## Global Constraints
- **No new Python packages.** Stdlib only (CONTRIBUTING: "stdlib only" tests).
- **Keys never in argv, logs, the state file, output or git.** They go to the server only as **stdin** of a fixed command.
- **Nothing that costs money without an explicit `yes`** to a price line showing the live `price_monthly` gross. A re-run never creates a second server.
- **The Hetzner token is never written to disk.**
- **State file:** `generated/up-state.json`, mode 600, keys `server_id name ip type location host_key stage`.
- **Types:** `cax11` ↔ `cx23`, `cax21` ↔ `cx33`.
- **Locations, in order:** `fsn1`, `nbg1`, `hel1`.
- **Image:** `ubuntu-24.04`.
- **Server end state:** identical to today's bootstrap + setup (root login off, admin key-only, ufw, Tailscale).
- **Never type into a running Claude session from a script.** The one-time prompts are pre-answered only through a supported setting confirmed by the probe (Task 7). Otherwise the user is told to attach once.
- **Stage order** (it changes the spec's list; the admin password goes last because `ADMIN_SUDO=limited` makes `tailscale up` and other root steps ask for a password): `create`, `ssh`, `copy`, `bootstrap`, `tailscale`, `claude`, `tokens`, `admin`, `setup`, `prompts`.

## Review Focus
1. **The state file names a server that no longer exists** (deleted in the console). Expected: say so and ask before creating a new one, with a fresh price `yes`. Never silently create a second one. → Task 5 test `test_gone_server_asks_again`.
2. **The user answers anything but exactly `yes` to the price**, e.g. `y`, `YES `, or empty. Expected: nothing is created, exit 1. → Task 5 test `test_price_needs_exact_yes`.
3. **A Hetzner API error body**, e.g. 401 bad token or 422 `resource_unavailable`. Expected: a one-line message with Hetzner's `error.message`, no traceback, no token in it. → Task 2 test `test_api_error_is_short_and_clean`.
4. **An existing `Host nori` block written by hand** in `~/.ssh/config`, outside the markers. Expected: never edited. Nori adds its own marked block only if no `Host nori` exists, otherwise it stops and asks. → Task 3 test `test_hand_written_host_is_left_alone`.
5. **`--host` given while a Hetzner state exists for a different IP.** Expected: refuse with the mismatch, never mix two servers in one state. → Task 5 test `test_host_mismatch_refused`.

```python
# scripts/nori/config.py
"""The resolved nori.conf (PRESET applied) as a dict, plus what ./nori up derives from it."""
import re
import subprocess
import tempfile
from pathlib import Path


def parse(text):
    out = {}
    for line in text.splitlines():
        m = re.match(r'^([A-Z][A-Z0-9_]*)=(.*)$', line.strip())
        if m:
            out[m.group(1)] = m.group(2).strip().strip('"')
    return out


def load(repo):
    """Render nori.conf the same way setup.sh does, so presets and validation are never duplicated."""
    with tempfile.TemporaryDirectory() as d:
        r = subprocess.run(["bash", str(Path(repo) / "setup.sh"), "--render-only", d],
                           capture_output=True, text=True, cwd=repo)
        if r.returncode != 0:
            raise SystemExit("nori.conf problems:\n" + (r.stderr or r.stdout).strip())
        return parse((Path(d) / "nori.resolved.conf").read_text())


def server_size(conf):
    return "large" if conf.get("PRESET") == "full" or conf.get("PLANE") == "true" else "small"


def needed_keys(conf, hetzner):
    names = (["hetzner"] if hetzner else []) + ["tailscale", "claude"]
    names += [f"bot:{a}" for a in conf.get("AREAS", "").split()]
    if conf.get("OPS_BOT") == "true":
        names.append("bot:ops")
    return names + ["admin_password"]
```

```python
# scripts/nori/keys.py
"""The keys checklist, hidden prompts and quick checks. Keys stay in memory; nothing here prints one."""
import getpass
import json
import re
import sys
from urllib.request import urlopen

CHECKLIST = {
    "hetzner": "Hetzner API token (Read & Write): console.hetzner.cloud → new project 'nori' → Security → API tokens",
    "tailscale": "Tailscale auth key (one-off, pre-approved): login.tailscale.com/admin/settings/keys",
    "claude": "Claude token: run `claude setup-token` on this laptop and copy what it prints",
    "bot": "Telegram bot token for {name}: @BotFather → /newbot",
    "admin_password": "A password for the server's admin user (12+ characters) for your password manager",
}


def label(name):
    if name.startswith("bot:"):
        who = name[4:]
        return CHECKLIST["bot"].format(name="the Ops bot" if who == "ops" else f"area '{who}'")
    return CHECKLIST[name]


def check(name, value, http=urlopen):
    if not value:
        return "empty"
    if name == "tailscale":
        return None if re.fullmatch(r"tskey-auth-[A-Za-z0-9-]+", value) else "should start with tskey-auth-"
    if name == "claude":
        return None if re.fullmatch(r"sk-ant-oat\d\d-[A-Za-z0-9_-]{20,}", value) else "doesn't look like a `claude setup-token` token"
    if name == "admin_password":
        return None if len(value) >= 12 else "use 12 or more characters"
    if name.startswith("bot:"):
        if not re.fullmatch(r"\d+:[A-Za-z0-9_-]{5,}", value):
            return "doesn't look like a BotFather token (digits:letters)"
        try:
            data = json.load(http(f"https://api.telegram.org/bot{value}/getMe", timeout=15))
        except Exception:
            return "Telegram didn't accept it (check the token, or your internet)"
        return None if data.get("ok") else "Telegram didn't accept it"
    return None  # hetzner is checked by its first API call


def ask_keys(names, prompt=getpass.getpass, out=sys.stdout):
    got = {}
    print("Keys (typing is hidden; nothing is saved on this laptop):", file=out)
    for n in names:
        print(f"  • {label(n)}", file=out)
    for n in names:
        while True:
            v = prompt(f"{n}: ").strip()
            problem = check(n, v)
            if not problem:
                got[n] = v
                break
            print(f"  ✗ {n}: {problem}. Try again.", file=out)
    return got
```

```python
# scripts/nori/hetzner.py
"""Just enough of the Hetzner Cloud API for ./nori up (stdlib urllib). The token lives only in this object."""
import json
import time
import urllib.error
import urllib.request

API = "https://api.hetzner.cloud/v1"
TYPES = {"small": ["cax11", "cx23"], "large": ["cax21", "cx33"]}
LOCATIONS = ["fsn1", "nbg1", "hel1"]


class HetznerError(Exception):
    pass


class Hetzner:
    def __init__(self, token, transport=None):
        self._token = token
        self._t = transport or self._http

    def _http(self, method, path, body):
        req = urllib.request.Request(API + path, method=method,
                                     data=json.dumps(body).encode() if body is not None else None,
                                     headers={"Authorization": f"Bearer {self._token}", "Content-Type": "application/json"})
        try:
            with urllib.request.urlopen(req, timeout=30) as r:
                return r.status, json.load(r)
        except urllib.error.HTTPError as e:
            try:
                return e.code, json.load(e)
            except Exception:
                return e.code, {}

    def _call(self, method, path, body=None, ok=(200, 201)):
        status, data = self._t(method, path, body)
        if status not in ok:
            msg = (data.get("error") or {}).get("message") or f"HTTP {status}"
            raise HetznerError(f"Hetzner: {msg}")
        return data

    def check(self):
        self._call("GET", "/locations")

    def pick(self, size):
        types = {t["name"]: t for t in self._call("GET", "/server_types")["server_types"]}
        avail = {}
        for dc in self._call("GET", "/datacenters")["datacenters"]:
            avail.setdefault(dc["location"]["name"], set()).update(dc["server_types"]["available"])
        for name in TYPES[size]:
            st = types.get(name)
            for loc in LOCATIONS:
                if st and st["id"] in avail.get(loc, ()):
                    price = next(p["price_monthly"]["gross"] for p in st["prices"] if p["location"] == loc)
                    return {"type": name, "location": loc, "price": f"{float(price):.2f}"}
        raise HetznerError(f"Hetzner: {' and '.join(TYPES[size])} are sold out in {', '.join(LOCATIONS)}. "
                           "Try again later, or pass --type / --location.")

    def ssh_key_id(self, name, pubkey):
        found = self._call("GET", f"/ssh_keys?name={name}")["ssh_keys"]
        if found:
            return found[0]["id"]
        return self._call("POST", "/ssh_keys", {"name": name, "public_key": pubkey})["ssh_key"]["id"]

    def create(self, name, type_, location, key_id):
        srv = self._call("POST", "/servers", {"name": name, "server_type": type_, "image": "ubuntu-24.04",
                                              "location": location, "ssh_keys": [key_id],
                                              "public_net": {"enable_ipv4": True, "enable_ipv6": True}})["server"]
        return {"id": srv["id"], "ip": srv["public_net"]["ipv4"]["ip"]}

    def server(self, sid):
        status, data = self._t("GET", f"/servers/{sid}", None)
        if status == 404:
            return None
        if status != 200:
            raise HetznerError(f"Hetzner: {(data.get('error') or {}).get('message', status)}")
        return data["server"]

    def wait_running(self, sid, timeout=300, sleep=time.sleep):
        for _ in range(max(1, timeout // 5)):
            srv = self.server(sid)
            if srv and srv["status"] == "running":
                return
            sleep(5)
        raise HetznerError("Hetzner: the server didn't reach 'running' in 5 minutes. Check the console, then re-run.")
```

```python
# scripts/nori/remote.py
"""ssh plumbing for ./nori up. Secrets only ever travel as stdin of a fixed command."""
import os
import re
import subprocess
import time
from pathlib import Path

BEGIN, END = "# >>> nori >>>", "# <<< nori <<<"


class RemoteError(Exception):
    pass


def ensure_key(home, run=subprocess.run):
    key = Path(home) / ".ssh" / "nori_ed25519"
    if not key.exists():
        key.parent.mkdir(mode=0o700, exist_ok=True)
        run(["ssh-keygen", "-t", "ed25519", "-N", "", "-C", "nori", "-f", str(key)], check=True, capture_output=True)
    return (key.parent / "nori_ed25519.pub").read_text().strip()


def upsert_host(config_path, alias, ip, user):
    p = Path(config_path)
    p.parent.mkdir(mode=0o700, exist_ok=True)
    txt = p.read_text() if p.exists() else ""
    outside = re.sub(re.escape(BEGIN) + r".*?" + re.escape(END) + r"\n?", "", txt, flags=re.S)
    if re.search(rf"(?mi)^\s*Host\s+(.*\s)?{re.escape(alias)}(\s|$)", outside):
        raise RemoteError(f"~/.ssh/config already has your own 'Host {alias}'. Rename it, or remove it, then re-run.")
    block = (f"{BEGIN}\nHost {alias}\n  HostName {ip}\n  User {user}\n"
             f"  IdentityFile ~/.ssh/nori_ed25519\n  IdentitiesOnly yes\n{END}\n")
    new = outside.rstrip("\n") + ("\n\n" if outside.strip() else "") + block
    p.write_text(new)
    os.chmod(p, 0o600)


def ssh(alias, command, stdin=None, run=subprocess.run, timeout=1800):
    r = run(["ssh", "-o", "BatchMode=yes", alias, command], input=(stdin + "\n") if stdin is not None else None,
            capture_output=True, text=True, timeout=timeout)
    return r.returncode, (r.stdout or "") + (getattr(r, "stderr", "") or "")


def wait_ssh(alias, run=subprocess.run, tries=60, sleep=time.sleep):
    for _ in range(tries):
        if ssh(alias, "true", run=run, timeout=20)[0] == 0:
            return
        sleep(5)
    raise RemoteError("The server didn't answer on SSH within 5 minutes. Check it's running, then re-run.")


def copy_repo(alias, repo, popen=subprocess.Popen):
    """Repo + nori.conf to /root/nori as a tar stream (no .git, no generated/: no secrets live in the repo)."""
    tar = popen(["tar", "-C", str(repo), "--exclude=.git", "--exclude=generated", "-cf", "-", "."],
                stdout=subprocess.PIPE)
    ssh_ = popen(["ssh", "-o", "BatchMode=yes", alias,
                  "rm -rf /root/nori && mkdir -p /root/nori && tar -x -C /root/nori"], stdin=tar.stdout)
    if ssh_.wait() != 0 or tar.wait() != 0:
        raise RemoteError("Copying the repo to the server failed. Re-run ./nori up.")
```

```python
# scripts/nori/stages.py
"""./nori up: ordered stages that skip what is done, with a state file that never holds a key."""
import json
import os
import shlex
import sys
from pathlib import Path

from . import config, hetzner, keys, remote

STAGES = ["create", "ssh", "copy", "bootstrap", "tailscale", "claude", "tokens", "admin", "setup", "prompts"]
ALIAS = "nori"


def _load(repo):
    p = Path(repo) / "generated/up-state.json"
    return json.loads(p.read_text()) if p.exists() else {}


def _save(repo, st):
    p = Path(repo) / "generated/up-state.json"
    p.parent.mkdir(exist_ok=True)
    fd = os.open(p, os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o600)
    with os.fdopen(fd, "w") as f:
        json.dump(st, f, indent=1)
    os.chmod(p, 0o600)


def _done(st, stage):
    return st.get("stage") in STAGES and STAGES.index(st["stage"]) >= STAGES.index(stage)


def run_up(repo, host=None, type_=None, location=None, env=None):
    e = env or {}
    out = e.get("out", sys.stdout)
    say = lambda m: print(m, file=out, flush=True)  # noqa: E731
    conf = e.get("conf") or config.load(repo)
    st = _load(repo)
    if host and st.get("ip") and st["ip"] != host:
        say(f"✗ generated/up-state.json is for {st['ip']}, not {host}. Move it away to start over.")
        return 1
    use_hetzner = not host and not st.get("host")
    k = e.get("keys") or keys.ask_keys(config.needed_keys(conf, hetzner=use_hetzner))
    ssh = e.get("ssh", remote.ssh)
    admin, areas = conf["ADMIN_USER"], conf["AREAS"].split()

    def step(name, fn):
        if _done(st, name):
            return
        say(f"⏳ {name}…")
        fn()
        st["stage"] = name
        _save(repo, st)
        say(f"✅ {name}")

    def run(cmd, stdin=None, alias=ALIAS):
        rc, text = ssh(alias, cmd, stdin=stdin)
        if rc != 0:
            raise remote.RemoteError(f"`{cmd.split()[0]}` failed (exit {rc}):\n{text[-1500:]}")

    try:
        # create: a Hetzner server, or the given host
        if use_hetzner:
            hz = e.get("hetzner") or hetzner.Hetzner(k["hetzner"])
            hz.check()
            if st.get("server_id") and hz.server(st["server_id"]) is None:
                say(f"⚠️ The server in generated/up-state.json (id {st['server_id']}) no longer exists.")
                st = {}
            if not st.get("server_id"):
                pick = hz.pick(config.server_size(conf))
                if type_:
                    pick["type"] = type_
                if location:
                    pick["location"] = location
                q = f"Create \"{conf['SERVER_NAME']}\" ({pick['type'].upper()}, {pick['location']}, €{pick['price']}/month)? Type yes: "
                if e.get("confirm", input)(q) != "yes":
                    say("Nothing created.")
                    return 1
                pub = e.get("ensure_key", remote.ensure_key)(e.get("home", Path.home()))
                srv = hz.create(conf["SERVER_NAME"], pick["type"], pick["location"], hz.ssh_key_id("nori", pub))
                st = {"server_id": srv["id"], "name": conf["SERVER_NAME"], "ip": srv["ip"], "type": pick["type"],
                      "location": pick["location"], "stage": "create"}
                _save(repo, st)
                hz.wait_running(srv["id"])
                say(f"✅ create ({srv['ip']})")
        elif not st:
            e.get("ensure_key", remote.ensure_key)(e.get("home", Path.home()))
            st = {"host": host, "ip": host, "stage": "create"}
            _save(repo, st)

        upsert = e.get("upsert_host", remote.upsert_host)
        cfg = e.get("home", Path.home()) / ".ssh" / "config"

        def to_root():
            upsert(cfg, ALIAS, st["ip"], "root")
            e.get("wait_ssh", remote.wait_ssh)(ALIAS)
        step("ssh", to_root)
        step("copy", lambda: e.get("copy_repo", remote.copy_repo)(ALIAS, repo))
        step("bootstrap", lambda: (run("cd /root/nori && bash bootstrap.sh"), upsert(cfg, ALIAS, st["ip"], admin)))
        step("tailscale", lambda: run(
            f"umask 077; f=$(mktemp); cat > $f; sudo tailscale up --auth-key=file:$f --hostname={shlex.quote(conf['SERVER_NAME'])}; rc=$?; rm -f $f; exit $rc",
            stdin=k["tailscale"]))

        def claude():
            for who in [admin] + areas:
                run(f"~/nori/server/bin/set-token claude {shlex.quote(who)}", stdin=k["claude"])
            for a in areas:
                run(f"sudo -u {shlex.quote(a)} -H bash -lc 'claude plugin marketplace add anthropics/claude-plugins-official; "
                    f"claude plugin install telegram@claude-plugins-official'")
        step("claude", claude)

        def tokens():
            for a in areas:
                run(f"~/nori/server/bin/set-token {shlex.quote(a)}", stdin=k[f"bot:{a}"])
            if "bot:ops" in k:
                run("~/nori/server/bin/set-token ops", stdin=k["bot:ops"])
        step("tokens", tokens)
        step("admin", lambda: (run("sudo chpasswd", stdin=f"{admin}:{k['admin_password']}"),
                               run("sudo bash ~/nori/bootstrap.sh")))
        step("setup", lambda: run("cd ~/nori && ./setup.sh --restart"))
        step("prompts", lambda: say(
            "One last thing only you can do: attach once to each session and answer its first-run questions\n"
            "(folder trust, CLAUDE.md imports, Enable Remote Control? y), then detach with Ctrl+b d:\n"
            + "\n".join(f"   ssh -t {ALIAS} attach {a}" for a in areas)))
    except (hetzner.HetznerError, remote.RemoteError) as err:
        say(f"✗ {err}\nFix that, then run ./nori up again: it continues from here.")
        return 1
    say("✅ Done. Send \"hi\" to your bot. To let it push to GitHub, see 'GitHub login' in docs/setup-guide.md.")
    return 0
```
